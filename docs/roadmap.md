# 当前能力与后续路线

已实现：本地工作台、隔离模拟后端、四种业务场景、模板基线、DeepSeek 工具调用客户端、执行边界、报告归档、自动化回归与 CI 配置。

待验证：使用用户本机密钥运行真实 DeepSeek 工具调用，并记录模型版本、输入、运行结果、调用次数与 Token。当前自动化模型测试均使用替身。

待开发：真实 Fineract 适配。需先运行隔离的 Fineract 测试环境，准备客户与贷款产品，再实现申请、查询、撤回 API 映射和数据清理。当前机器 Java 17，而所阅读上游基线要求 Java 25；Docker 服务当前不可用，因此不能声称真实集成已完成。

后续可扩展：审批前后状态约束、越权访问、多账户数据隔离、幂等行为、同一固定用例集上的模板与真实模型对比。每项都应先有业务契约和可重现实测，再加入简历。

公开仓库不是业务上线证明。面试价值来自能现场运行、解释业务断言、指出故障证据并说明设计取舍。
